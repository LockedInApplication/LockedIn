# LockedIn

LockedIn is a relationship transparency platform that helps users mutually confirm relationships and gain clarity about the connections they are part of.

Unlike traditional dating apps that focus on matching, LockedIn focuses on **trust and accountability**. When two people confirm a relationship, the platform tracks connection patterns and can notify users if unusual situations—such as overlapping relationships—appear.

LockedIn does **not make accusations**. Instead, it provides **soft alerts**, allowing users to decide how they want to interpret and respond to the information.

## Tech Stack

- **Frontend:** Next.js, TypeScript, TailwindCSS  
- **Backend:** Node.js, TypeScript  
- **Database:** PostgreSQL with Prisma ORM  
- **Infrastructure:** AWS Lambda, Infrastructure as Code

## Goal

To build technology that promotes **honesty, transparency, and informed decision-making in modern relationships**.
